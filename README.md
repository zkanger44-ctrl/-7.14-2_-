# ゲーム設計7.14の2 修正版

添付「20261006 設計応用.pptx」3枚目の6項目を既存コードに組み込みました。

| 資料の要素 | 実装 |
| --- | --- |
| コンストラクタ | Player: 能力値とクリティカル率を初期化。ConsoleRpg: 乱数と勇者を初期化 |
| ファクトリーパターン | CharacterFactory: 勇者生成、ID指定・ランダムの敵生成 |
| データテーブル | Enemy.cppの敵一覧とGameDataTableの勇者初期設定 |
| シングルトン | GameDataTable::Instance(): マスターデータを一度だけ生成。コピー禁止 |
| 有限状態機械 | GameStateとConsoleRpg::Run(): 遭遇→各ターン→勝利/敗北→次戦/終了 |
| オブジェクトプール | EnemyPool: 最大4体を保持。返却した実体を再利用し、HPなどを初期化 |

## 起動方法

- ConsoleRpg.exeを実行すると、自動でターン制バトルが進みます。
- コードを編集する場合は「ゲーム設計7.14の2.sln」をVisual Studio 2022で開きます。
- C++17とUTF-8の設定を全構成に追加済みです。

## ゲームの動作

既存の4種類の敵、能力値、SPDによる先攻判定、クリティカル攻撃、最低1ダメージを維持しています。
プールの再利用と状態遷移を確認できるよう、3連勝でクリアする連戦を追加しました。
勝利後はHPを200回復します（初期HP1000が上限）。敗北すると終了します。
敵の選択は毎回ランダムなので、同じ敵が続く場合もあります。
敵マスターは読み取り専用で、戦闘中のHPは敵の実体だけに反映されます。
MPは元コードと同様に能力値として保持し、魔法やコマンド入力は追加していません。

## ファイル

- GameDesign.h: 各設計要素のクラスと状態定義
- ゲーム設計7.14の2.cpp: 戦闘処理・状態遷移・開始処理
- Enemy.cpp / Enemy.h: 敵のマスターデータ
- PlayerSettings.h: 能力値の共通構造体

## 検証

MSVCでC++17・UTF-8・警告レベル4のビルドと実行を確認しました。
この環境ではMSBuildのSDK自動探索にアクセス制限があるため、実行ファイルはインストール済みMSVCで直接ビルドしています。
